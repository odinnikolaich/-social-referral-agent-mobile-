# -social-referral-agent-mobile-# Social Referral Agent Mobile

Автономный open-source агент для соцсетей и реферальных программ — работает на телефоне через Termux.

## 🔧 Установка
1. Установите Termux (F-Droid)
2. Клонируйте репозиторий
3. `pip install -r requirements.txt`
4. Настройте `config.json`
5. Запустите: `python3 main_agent.py`

## 📁 Структура
- `main_agent.py` — главный агент
- `content_templates/` — шаблоны для YouTube, TikTok, Reels
- `hashtags/` — хештеги для Skillbox и модульных домов
